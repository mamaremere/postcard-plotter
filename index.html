✒️ Postcard Plotter

Type a message and the address, choose a handwriting font, download G-code for Candle.

Message

One paragraph per line — don't press Enter at the end of each line, the layout wraps for you and packs tighter. A blank line starts a new paragraph.

Address

One address line per row, exactly as it should appear — address lines are never re-wrapped. Leave it empty to plot the message only.

A UK address usually runs to 5 or 6 lines (name, house and street, locality, post town, county, postcode). Reserving room for that many keeps every card's address the same size, whether a particular one has 3 lines or 6.

Handwriting

Single-line SVG fonts only. Ordinary fonts (TTF/OTF) are outline fonts and would plot as hollow double letters.
